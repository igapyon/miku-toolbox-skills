# miku-toolbox 仕様

## 合意済みの製品方針

`local-html-tools` の利用者向け機能を、会話から使える Agent Skill へ段階的に移植します。

- 製品名は `miku-toolbox`、リポジトリ名は `miku-toolbox-skills`、インストールする Skill 名は `igapyon-miku-toolbox` とします。
- 機能をまとめた単一 Skill とし、ほかのツールも同じ Skill に追加します。
- Node.js のみ対応する Skill-only 製品とします。
- 初版の対象はパスワード生成です。
- 既定値を含め、元ツールの生成規則を尊重して引き継ぎます。
- 製品バージョンは `0.4.0`、対応する Git タグは `v0.4.0` とします。
- 配布 ZIP は `igapyon-miku-toolbox-skills-<version>.zip` とし、任意の GitHub Release asset とします。
- 対応 Node.js は、最古の保守中 LTS である 22 以上とします。CI は 22 と 24 で実行し、ZIP の作成基準は 24 とします。
- 生成インデックスは使いません。Skill は単一で参照文書も少なく、`SKILL.md` から直接たどれるため、別の索引による選択性の向上がありません。

## パスワード生成

参照元は `local-html-tools` のパスワードジェネレーターです。確認したコミットとファイルは [開発メモ](development.md) に記録します。

### 入出力と既定値

入力は文字数と4文字種それぞれの使用有無です。1回の生成でパスワード1件を出力します。

| 項目 | 既定値 |
| --- | --- |
| 文字数 | 8 |
| 英大文字 | 使用する |
| 英小文字 | 使用する |
| 数字 | 使用する |
| 記号 | 使用する |

### 文字集合

使用する文字は次の固定された ASCII 文字です。

| 文字種 | 使用可能な文字 |
| --- | --- |
| 英大文字 | `ADEFHMNRTY` |
| 英小文字 | `adefhmnrty` |
| 数字 | `0123456789` |
| 記号 | `@#$` |

### 入力条件

- 文字数は1以上の整数とします。
- 文字種を1つ以上選択します。
- 英大文字・英小文字の少なくとも一方を選択します。
- 文字数は選択した文字種の数以上とします。

条件を満たさない入力では、生成せずに理由を返します。

### 生成規則

- 先頭文字は、選択された英大文字または英小文字とします。
- 選択した文字種それぞれから、最低1文字を含めます。
- 使用可能な文字を使い切るまでは、同じ文字を再利用しません。
- 指定文字数が使用可能な文字数を超える場合は、全ての使用可能な文字を一度使用した後、重複を許して指定文字数まで生成します。
- 元実装では、先頭を固定して残りの文字をシャッフルします。この振る舞いを互換性の基準にします。
- Node.js 上で暗号学的乱数を使うヘルパーを実行して生成します。

全4文字種を選択した場合、使用可能な文字は33文字です。33文字までは重複せず、34文字以上では重複を許します。

互換性は条件・既定値・生成規則で判定します。乱数により生成される個別の文字列は固定しません。

## 会話インターフェース

以下を初版の会話契約とします。

| 依頼例 | 想定する動作 |
| --- | --- |
| パスワードを生成 | 既定条件で1件生成する |
| 16文字、記号なしで生成 | 文字数と記号の使用有無を変更して1件生成する |
| もう一つ | 直前と同じ条件で新しく1件生成する |

- Skill は `igapyon-miku-toolbox`、`miku-toolbox`、`miku-toolbox-skills` を利用者が明示した場合に使います。起動済みの会話では続けて利用できます。一般的なパスワード生成依頼だけでは自動的に適用しません。
- Skill 名だけで呼ばれた場合は、利用可能な機能を案内し、操作内容を尋ねます。操作を推測して秘密文字列を生成しません。
- 条件なしで新たに「パスワードを生成」と依頼された場合は既定条件を使います。
- 文字数や文字種の一部だけが指定された場合、指定された条件を反映し、残りは同じ会話内で直前に生成が成功した条件、または既定値で補います。
- 「もう一つ」は同じ会話内で直前に生成が成功した条件を使います。条件は会話の外へ保存しません。
- 生成結果はコピーしやすい単一の文字列として返します。

### Node.js ヘルパー CLI 契約

- `node skills/igapyon-miku-toolbox/lib/password-generator.mjs` で実行します。
- `--length <整数>` は生成文字数を指定します。省略時は `8` です。
- `--exclude <upper|lower|digits|symbols>` は文字種を無効にします。複数回指定できます。省略時は全種類を有効にします。
- 成功時はパスワードだけを標準出力へ1行で出します。
- 引数や条件が不正な場合、理由を日本語で標準エラーへ出し、終了コード `2` を返します。スタックトレースは表示しません。
- `--help` は使用方法を標準出力へ出し、終了コード `0` を返します。

## 初版の完了条件

- インストールする Skill が1つにまとまっていること
- Node.js で同梱ヘルパーを呼び出し、元リポジトリのローカル配置に依存せず生成できること
- 既定の8文字で、先頭が英字、全4文字種を含む、文字の重複がない、という条件を満たすこと
- 有効な文字種の組み合わせと指定文字数で、固定文字集合と生成規則を満たすこと
- 使用可能文字数と同じ長さ、およびそれを超える長さで、重複の扱いが規則に沿うこと
- 不正な文字数、文字種の未選択、数字・記号だけの選択、文字種数より短い指定を拒否すること
- 配布物に必要な文書と実行用ヘルパーが含まれること
- Apache-2.0 のライセンス本文を Skill 内に含めること
- `.DS_Store` と Skill 直下の作業用 `tmp/`、`output/`、`state/` をバンドルとローカル配備から除外すること
- 必須ファイルが欠落または空の場合、既存のバンドルやローカル配備先を置き換える前に中止すること

実装状況と残る検証は [TODO](../TODO.md) と [開発メモ](development.md) に記録します。
